ESP32 IoT Server

A custom IoT communication system where ESP32 devices send sensor data to a Python server through Wi-Fi.

View Source Code Architecture
01

Project Overview

📡

ESP32 Communication

ESP32 connects to Wi-Fi and communicates with the custom Python server.

🖥️

Python Server

Python server receives device data and processes the incoming IoT messages.

🔑

API Access

Each ESP32 device can use a unique device ID and API access key.

📊

Live Data

Sensor values can be displayed through a web dashboard.
